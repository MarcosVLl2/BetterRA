# SCPlugins

SCPlugins is a repo where I create fun plugins that I get inspired to do (or paid to do), all the SCP Plugins I create will be updated here.

## Current Plugins:
* **BetterRA:** (or Better RemoteAdmin) is an SCP:Secret Lab plugin based on pure LabApi to implement a new and reformed RemoteAdmin interface, with more additions for server hosters to be able to do as they please.
